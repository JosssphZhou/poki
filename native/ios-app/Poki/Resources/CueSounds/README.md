# Task cue sounds

Audio from [UI SFX](https://github.com/romainsimon/uisfx), by Yuki Capital, released under **CC0 1.0 Universal**. The upstream audio license is included in [LICENSE-AUDIO.txt](LICENSE-AUDIO.txt).

Pinned upstream revision: `9950fe66f993a6660dab9c2651dcbcd899ffd83b`.
Original directory: [`packages/uisfx/sounds/minimal/`](https://github.com/romainsimon/uisfx/tree/9950fe66f993a6660dab9c2651dcbcd899ffd83b/packages/uisfx/sounds/minimal).

| Event | Original | Playback resource |
| --- | --- | --- |
| Task begins execution | start.mp3 | start.caf |
| Owner approval appears | notification.mp3 | notification.caf |
| Task completes | complete.mp3 | complete.caf |
| Task fails | blocked.mp3 | blocked.caf |

The MP3 files are unchanged upstream originals. The CAF files contain the same decoded audio, converted to 16-bit linear PCM for iOS System Sound Services. No trimming, gain, normalization, resampling or pitch changes are applied. Reproduce each conversion with `ffmpeg -i start.mp3 -c:a pcm_s16le start.caf`, substituting the corresponding name.

`cue-silence.caf` is 50 ms of zero-valued mono PCM generated by Poki. ActivityKit requires an alert sound, so this file preserves the visual approval and completion alerts while the cue player owns their sound. Approval reminders also use silence to avoid replaying the same request. Generate it with `ffmpeg -f lavfi -i anullsrc=r=44100:cl=mono -t 0.05 -c:a pcm_s16le cue-silence.caf`.

The player prepares sound IDs on a serial background queue at app startup. Task execution does not wait for file I/O or preparation. Playback uses System Sound Services without changing the audio session, volume, or silent-switch policy.
